# 阶段一：角色常驻音乐播放器最小原型

这一阶段只验证生命周期，**还不是制作器，也不是四主题最终产品**。正式音乐插件仍为 1.10.0，原曲库、歌单、角色绑定和 IndexedDB 都不改。角色卡使用者只需要酒馆助手，不需要安装完整版音乐插件。

## 可下载的测试文件

- [酒馆助手脚本 JSON](dist/demo.tavern-helper.json)：推荐使用，下载文件后导入“角色脚本库”。这是脚本，不是完整版插件离线安装包。
- [独立 JavaScript](dist/demo.js)：也可以新建角色脚本，把全文粘贴到代码区。
- [测试歌曲清单](dist/songs.json)：三段本项目生成的 120 秒低音量 MP3 测试音，音高不同，均非参考角色卡音乐。

音频以 `data:audio/mpeg;base64,...` 随脚本携带。在已验收的浏览器/助手版本中可以离线解码播放，不含当前制作电脑的 blob URL、IndexedDB ID 或本地文件路径。角色 PNG 携带的是脚本中的这些字节；删除制作电脑上的测试音源文件不会影响已经导出的脚本。**这只验证了约 1 MB 三曲原型的方案，不代表可以无限量嵌入大型商业曲库，也不表示已完成未来真实歌曲的导出资源方案。**

## 给角色卡作者的安装步骤

已实测：SillyTavern 1.19.0 + 酒馆助手 4.11.3。酒馆助手安装来源为 [官方仓库](https://github.com/N0VI028/JS-Slash-Runner)，本项目不重新分发助手实现。

1. 打开你要添加播放器的角色卡。
2. 下载本目录的 `dist/demo.tavern-helper.json`，在 **扩展 → 酒馆助手 → 脚本 → 导入** 中，目标选择 **角色脚本库**，确认后选择该文件。
3. 打开 **角色脚本库开关**，再打开 **“角色播放器 · 三曲生命周期测试”脚本本身的开关**。助手导入时会自动把脚本设为停用，两个开关都要打开。
4. 主页面会出现小型测试播放器，点播放开始听测试音。点击 × 收起为黑胶悬浮球；点击唱片展开，收起不停止播放。
5. 使用酒馆正常导出角色卡。发送给使用者时，应发送导出的角色 PNG；不要只发送聊天消息或当前浏览器存储。
6. 使用者安装酒馆助手、导入角色卡并进入该角色，允许/启用该卡的角色脚本后就能使用。播放器不要求安装完整版音乐插件。

不要放入全局脚本库、某条聊天消息、正则替换的 HTML 或开场白 HTML。脚本会校验自己确实来自当前角色的已启用脚本；错误位置会拒绝启动。

## 这一阶段的明确行为

- 进入角色：播放器自动显示，音频不自动播放，以避免浏览器自动播放限制。
- 同一角色内聊天、切开场白、切 AI 回复、编辑消息、重新生成、换另一个聊天：保留同一音频对象、歌曲和进度。
- 切换别的角色或回主页：立即暂停、移除音源、销毁 DOM 和监听器。
- 返回原角色：创建新的播放器；本阶段从头开始且不自动播放。音量按角色单独记忆，不跨角色串用。
- 停用、删除、重新加载角色脚本：销毁旧实例；重新启用会创建新实例。手动重载脚本属于失活/重启，不属于同一角色内的普通消息操作。
- 同一角色/同一播放器项目重复执行：复用已存在的实例，不重新注册监听器，不创建第二个音频对象。
- 没有轮询定时器，不观察聊天消息 DOM。仅观察脚本 iframe 是否被移除，作为脚本失活的额外清理保障。

独立播放器使用开放的 Shadow DOM 隔离宿主样式。存储键为 `riserein:card-player:v1:<项目ID>:<角色头像标识>`，只保存本原型音量，不读取/修改完整版插件的数据。

## 验收范围

真实助手测试、版本、限制及截图见 [阶段一审查与验收报告](../docs/card-player/stage-one.md)。手机验证采用 Chromium 窄屏和触屏模拟，尚未声称实体 iOS/Android 与所有助手版本均已验收。

请先用自己的角色卡验证生命周期。制作器、正式资源检查/导出系统、完整核心控制及四组主题均留到最小原型确认之后。

## 开发者复现

```sh
npm ci
npm run build:card-demo
npm run check
npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:card
```

最后一条需要**独立测试酒馆**安装真实酒馆助手 4.11.3，并将完整版音乐插件仓库放在测试酒馆的 `public/scripts/extensions/third-party/sillytavern`。测试通过设置隔离禁止加载完整版播放器，再实际创建临时角色、使用助手脚本、保存聊天、导出/导入 PNG，最后只删除 `RSCP_Test_` 前缀的测试角色。不要针对日常酒馆数据运行。角色套件会保存测试角色脚本设置，并在该测试配置中禁用完整版插件；与完整版回归切换时，请使用另一份干净的测试配置，或先在独立测试酒馆重新启用完整版插件。

助手测试使用的是官方提交 `a0f3a180344cff38a4b3e75041d5a94380b877d6`；不是伪造的助手接口。普通 `npm run test:e2e` 保留原有回归范围，不强迫所有开发者为普通播放器回归安装助手；角色测试有单独的 `playwright.card.config.js`。

构建使用固定 esbuild 0.25.10 临时工具，不增加运行时框架。原始合成音在 `demo-assets/`，可用 ffmpeg 的 sine 音源生成：220/277/330 Hz、22050 Hz 采样率、120 秒、`volume=0.10`、libmp3lame 16 kbps。构建前所有验证完成后才写入 `dist/`，没有打包参考作者的资源。
