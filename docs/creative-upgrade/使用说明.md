# 歌词编辑与日常体验

## 修正逐句歌词

1. 打开曲库中的歌曲，点右侧「⋯ → 逐句歌词时间轴」。
2. 左侧播放、暂停与进度使用当前歌曲；右侧可输入时间、提前／延后 0.1 或 0.5 秒，或点「当前时间」。点歌词或「试听」可跳到该句。
3. TXT 可先导入，播放后听到每句开头点「标记当前时间 · 下一句」。未全部打点时不能保存为同步歌词。
4. 检查提示，点「确认保存歌词」。取消会丢弃未保存编辑。最多撤销／重做 40 步；「恢复编辑前原版」恢复首次修改前的完整歌词。
5. 可导出新的 LRC；原文件、原音频不会被改写。LRC 文件 offset 和整曲个人校准都会参与计算，提示栏会分别显示两项。

若正式歌词在编辑期间被其他操作修改，保存会中止，避免覆盖新内容。请先保留自己的 LRC，再关闭并重新读取。

完整版将原版和修改后的歌词保存到现有曲库，并纳入 ZIP 备份。随卡接收端的修改保存在当前账号／角色／脚本的个人偏好中，不改作者的卡；重建分发仍由制作端完成。浏览器禁止本地存储时会提示仅本次会话有效。

## 跟随歌曲封面配色

在「外观 → 封面自动取色」选择柔和或明显跟随，关闭可回到原主题。取色不上传封面、不调用外部服务。明确的自定义颜色和场景主题优先；无法安全读取跨域图片时沿用主题。作者禁止接收端改变设计时，相应选项不可修改。

## 快速切换角色场景

角色有至少两个已完成且参与分发的场景时，右键悬浮球，或在触屏上长按约半秒。菜单显示场景名、歌曲数和当前选择；选择后沿用原场景切换规则，共享当前歌曲时保持进度，暂停时保持暂停。

拖动会取消长按；彻底隐藏后不能通过这个入口误恢复。仍可使用原来的魔棒恢复和普通场景入口。

# v2.2.0 音景

播放页下方展开「音景」，进入「环境音库」导入自己的雨声、海浪等音频，或添加稳定公开的 HTTPS 音频直链。可修改名称、默认音量、循环、图标及本地封面；环境音库最多 50 项。它与歌曲库分开，不计入收藏、最近播放和排行。

主音乐和环境音分别调整音量、播放或暂停。默认暂停主音乐时环境音继续，可取消这一选项；「全部暂停」停止双轨，之后可点「恢复播放」。睡眠定时结束也会停止双轨。关闭普通窗口或贴边仍可播放；使用「隐藏角色音乐」会停止全部声音，魔棒恢复后不会自动播放。

在「角色音乐场景」中给各场景选择环境音、音量、默认开关和过渡。支持无过渡、0.5／1／2 秒。同一环境音跨场景复用时保持进度；切换不同环境音先淡出再淡入。个人关闭和音量调整优先；「恢复场景默认」取消这些个人覆盖。MP3 编码可能带首尾间隙，不保证每个文件都能无缝循环。

保存绑定并从酒馆原生菜单重新导出的 PNG／JSON 会携带所选场景的环境音。接收者无需完整版插件，仍需酒馆助手及角色脚本许可。制作器请点击「读取当前角色场景」取得音景快照；项目会保存音频副本，源库后续删除不会破坏已保存草稿。独立 JS、Helper 脚本和 HTML 预览会使用共享界面；预览开始前暂停完整版声音。

相同环境音按实际字节去重；与主歌曲完全相同时可复用歌曲资源。仍遵守单音源 20 MiB、所有内嵌资源 30 MiB 和脚本 45 MiB 上限，不会自动转码或删歌。资源缺失、格式无法播放或超限时会阻止导出，保留旧角色卡。

ZIP 完整备份包含本地环境音、封面、场景设置和草稿副本；直链只备份地址和信息，不是离线音频。恢复前核对角色映射、环境音数量及空间估算。存储管理把环境音单独列出，共享的库资源只计一次；浏览器只提供整个站点配额估算，草稿计数属于逻辑字节。

环境音失败不会停止主音乐。移动浏览器可能限制程序调节音量；实体手机的实际增益效果仍需验证。

## 双语歌词（2.3）

在曲库歌曲详情点「逐句译文匹配」，填写语言和译者／来源。导入译文 LRC 时会给出相近时间的匹配建议；TXT 不会假装自带同步，可逐句选择、填写或先按顺序生成待确认草稿。检查原文与译文后勾选确认再保存。未填的句子保留原文。

外观的「文字与阅读 → 双语歌词」可选原文、双语、译文，并分别调整字号、行距、颜色和间距。沿用原来的连续滚动、居中、单句沉浸模式。无对应译文的句子仍显示原文。颜色仅在显示层保护对比度，不改写作者保存的原色。

时间轴编辑器会预览对应译文；微调原文时间不改译文文件，也不按排序后的序号重新配对。原文字句变化或插入／删行后，失去对应的译文会保留并提示制作端重新确认。要随卡携带，须明确勾选「随角色卡携带译文」和分发授权，并填写来源说明；只在本机使用的译文不会进入分享卡。

## 作者手记与我的手记（2.3）

手账的 Notes 页面有「作者手记」和「我的手记」。前者随卡分发；后者只在当前账号的私人数据库保存，按角色、脚本和项目隔离。可新建、修改、删除多条，关联保存当时的歌曲、场景和日期。每条最多 2000 个字符，账号合计最多 200 条、1 MiB。

切歌时，正在写的草稿保留原歌曲关联，避免误存到下一首。切卡或关闭酒馆前请点保存：未保存的输入不是自动保存草稿。并发修改会提示重新读取，不覆盖另一窗口的新文字；配额不足时原内容保留。

「私人手记备份与恢复」可导出本角色的私人 JSON，导入时明确归入当前角色／脚本并创建副本。全文版「外观 → 数据备份与恢复」也可**主动勾选**将当前账号手记加入 ZIP；默认不包含。此文件有私人文字，请勿随角色卡分享。

ZIP 内的手记与曲库分开确认恢复，避免假装浏览器与酒馆保存属于一个事务。先核对原角色映射；恢复曲库后再恢复手记，会沿用曲目／场景的新 ID。相同备份、相同映射重复确认不会重复写入或覆盖已有文字。缺少对应曲目的手记保留原曲名，可开启「显示本角色全部手记」。角色副本、重新导入后的 avatar 或脚本身份变化时，请明确使用私人备份迁移，不按相同角色名自动合并。

私人手记从不写回作者角色卡、作者备注或分享模板；不读取聊天、不调用 AI，也不上传给作者。浏览器同源内已被允许运行的其他扩展／角色脚本仍具有该站点权限，本功能不是对恶意同源脚本的加密隔离。

## 手账自由排版（2.3）

打开「播放器设计器」，选择 Music Journal，再在属性中将排版模式设为「自由排版」。原书本模式和四套纸张主题仍可直接使用，不自动迁移。

四个独立页面为音乐、歌词、手记和目录。可添加文字、静态图片、封面、歌名／歌手／专辑、真实歌词阅读器、当前译文、作者手记、场景介绍、真实队列、播放控制及分割线。播放控制和歌词沿用现有播放器，不会新增主音乐声道。

打开「排版操作」后，可拖动元素、拖右下角缩放；关闭它可直接试听。图层列表支持多选，桌面也可按 Ctrl／Shift 点选；提供位置、大小、字体、行距、颜色、透明度、圆角、同类层级、复制／删除、隐藏／锁定、多选对齐、5% 网格和中线参考。真实播放／歌词组件每页最多一份。文字层在图片层之上，正文透明度最低 85%；需要移除请隐藏。

**桌面／手机分别保存坐标。**用预览顶部的设备按钮切换后再排版；窄屏设计器用「模板／预览／属性」切换。手机坐标不是把桌面像素等比例缩小。预览、拖动和翻页不换音频，只有应用设计或保存模板后才写入正式配置。关闭设计器会撤销未应用的预览。

本地图片只接受静态 PNG／JPEG／WebP，单张不超过 2 MiB、2048×2048，单套拼贴合计不超过 8 MiB，每页最多 24 个元素，四页总文字最多 50,000 字符。SVG、GIF、动画 PNG／WebP、HTML、脚本、任意 CSS 和远程代码不支持。可主动勾选这次导入的 WebP 优化；不会处理或改写音频。相同字节的本机拼贴图片复用资源引用。

设计设置只保存资源 ID；制作草稿保存图片副本，ZIP 以校验过的二进制文件保存，分享模板文件暂时包含所需图片数据。模板导入会重新校验并分配本机资源 ID。原生 PNG／JSON、独立 JS、Helper 格式和 HTML 预览携带当前设计需要的图片，仍须遵守全部内嵌资源 30 MiB 和脚本 45 MiB 的原限制。

更新插件不会远程更新已经发出的角色卡。制作端保存／重建绑定后重新导出，接收端仍须安装并启用官方酒馆助手、允许可信角色脚本；不需要完整版音乐插件。
