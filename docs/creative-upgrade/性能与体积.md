## 同夹具前后对比

其他浏览器套件结束后，按“基线 → 当前”交替串行执行三轮。同为夜航布局、29 MiB 合成 WAV、独立 Chromium 154、384 MiB V8 old-space 限制；该限制不是浏览器进程总内存限制。使用同一测试脚本和配置，不带酒馆／Helper，不加载大型装饰图。

| 指标 | 基线 | 2.3.0 |
|---|---:|---:|
| 同步挂载中位数 | 188.3 ms | 203.5 ms |
| 首次 loadeddata／可播放中位数 | 590.5 ms | 629.0 ms |
| 心跳最大观测间隔（三轮） | 235.4 ms | 250.4 ms |
| 500ms 样本中最高 JS 堆 | 55.7 MiB | 50.1 MiB |
| 500ms 样本中最高各进程 RSS 相加 | 771.8 MiB | 778.7 MiB |
| 销毁后播放器根节点与已登记资源 | 0 | 0 |

挂载约增加 15.2 ms，可播放约增加 38.5 ms；三次小样本不证明统计显著，也不能宣称全面加速。当前自由手账另一次同容量测试为挂载 198.6 ms、可播放 637.4 ms，资源归零；仅一次样本，不作为跨版本排名。

`Runtime.getHeapUsage` 与页内 `performance.memory` 采样时刻不同、可能跨 GC，不能相减宣称净占用或峰值；大段主线程任务期间采样会延迟。RSS 相加包含共享页的重复记账，不能当作真实独占物理内存。早期 large-baseline.json／large-v230.json／large-collage-v230.json 在其他测试并行时采集，保留原始记录，但不用作上述控制比较。

## 真实酒馆接近容量上限

SillyTavern 1.19.0 + 官方 Helper 4.11.3，实际原生菜单导出、服务器导入、Helper 许可、实际 WAV 解码／播放及退出清理。区别于上一节独立夹具：宿主、Helper、角色数据和多份脚本解析均计入。

| 操作 | 实测 |
|---|---:|
| JSON 导出（菜单操作到下载读取） | 46.293 s |
| PNG 导出 | 94.431 s |
| PNG 导入（上传到角色列表确认） | 43.390 s |
| 改选字体后 JSON 导入 | 33.029 s |
| PNG 角色进入到首个播放器显示 | 12.740 s |
| PNG 角色进入到首次音频 loadeddata | 14.348 s |
| JSON 角色进入到首个播放器显示 | 9.475 s |
| JSON 角色进入到首次音频 loadeddata | 10.838 s |

上述进入时间从测试选择角色前开始，包含宿主切换、Helper 脚本准备及用户许可操作，不是单独组件 mount 耗时。主音乐实际播放进度推进，离开角色后已登记 timer／URL／监听／字体／解码／Blob 等计数归零。没有对退出后进程 RSS 立即回到初值作保证，V8 与宿主缓存回收并非同步。

全流程采样中：作者页面最高观测 JS 堆约 1,037.1 MiB、进程 RSS 相加约 3,497.2 MiB；接收端约 1,385.3 MiB／3,019.8 MiB。最长观测 Long Task 分别 6,976 ms／3,445 ms。它们是包含宿主与 Helper 的样本最大值，不是真实峰值，也不能全部归因于插件。

这说明大型卡仍会慢、仍可能在低内存手机上失败。没有相同宿主大卡的基线完整性能采样，不能宣称这组导入导出已比旧版加速。改进包括装饰图片几何编辑复用 DOM／URL、按页缓存与释放、环境音按字节去重、原有字体／PNG 复用；没有转码音频、删除资源、提高容量上限或引入外部压缩服务。

## 复测

- `npm run check`、`npm test`。
- 启动独立测试酒馆，设置 `CHROMIUM_PATH` 和 `ST_BASE_URL`，按现有 Playwright 配置执行。
- 接近上限：`ST_AUDIT_LARGE=1 ST_AUDIT_PERF=1 npm run test:card-native -- --grep 'compact selected font stays'`；此项全流程可能数分钟，禁止使用日常数据目录。
- 独立夹具：`ST_LARGE_REPORT=<报告路径> npm run audit:large-player -- <标签>`；指定 `ST_RUNTIME_FILE` 可比较冻结版本，`ST_DESIGN_LAYOUT=journal` 检查自由手账。
- 同一服务器上会保存宿主设置的用例须串行；并发设置写入会污染验证结果。

实体手机、Safari／WebKit／Firefox、真实外网音频未在本报告验证。合成 WAV 可压缩性、音频格式、用户角色卡内容和磁盘速度均不同，不外推为真实商业 MP3 的性能。
