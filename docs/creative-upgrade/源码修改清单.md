# 源码修改清单

比较基线 `fbf8b78` 与当前 2.3.0 工作树；生成文件、截图和原始日志另存，测试文件单列。本清单只列实际修改，不代表每一项都在所有浏览器验证。

## 模块职责

| 模块 | 职责及兼容方式 |
|---|---|
| `lyric-document.js`、`ui/lyric-editor.js` | 逐句时间轴、原文保留、校验、撤销重做、显式保存与冲突检查。 |
| `ui/cover-colors.js`、`ui/scene-quick.js` | 本地封面取色、锁定色和场景优先级、复用原悬浮球场景入口。 |
| `ambient.js`、`ui/soundscape.js`、`card-player/ambient-transport.js` | 单一辅助 Audio、环境音库、场景控制、按字节去重、各导出方式运输。 |
| `translations.js`、`ui/translation-editor.js`、`ui/lyric-reader.js` | 规范译文、明确关联／来源／授权、原始文本不改写、三模式共享同步。 |
| `private-notes.js`、`ui/private-notes.js` | 独立账号数据库、角色／脚本／项目隔离、版本冲突、限额、私人副本导入。 |
| `ui/collage-*`、`ui/raster.js`、`card-player/collage-transport.js` | 扁平数据式编辑器、独立手机坐标、真实组件复用、二进制图片验证和运输。 |
| `ui/config.js`、`ui/editor.js`、`ui/presentation.js`、`ui/journal.js`、`ui/creative.css` | 可选自由手账、设计器集成、全主题样式与旧书本保持兼容。 |
| `data/backup.js`、`restore.js`、`panel.js`、`storage.js` | 新元数据与二进制纳入已有 ZIP／映射／引用；私人文字单独选择及提交。 |
| `card-player/project-store.js`、`resource-references.js`、`asset-retirement.js` | 草稿保存音频／图片副本，安全清理先检查全部有效引用。 |
| `index.js`、`core.js`、`music-scenes*.js`、`card-player/*export.js`／`*entry.js` | 原播放和生命周期入口接入新功能，不新建主播放引擎。 |
| `ids.js` | 抽出已有随机 ID，core 保持原 API，HTTP LAN 使用 getRandomValues。 |
| `card-player/dist/*` | 从当前源码重新生成原生运行时、共享 UI、经典运行时与演示脚本。 |

## 数据结构

现有音乐／项目 IndexedDB schema 不变。歌曲可选 `translation`，设置新增／扩展 `ambientLibrary`、`soundscape`、`coverColorMode`、双语 `reading` 偏好、可选 `uiDesign.collage` 和 `customization.journalMode`；场景可选环境音。旧字段与旧布局保留。作者配置白名单不加入私人手记。新增私人库 `riserein-private-notes-v1:<verified-account>` 仅存纯文字与关联信息。
