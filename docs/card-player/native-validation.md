# 1.12.3 原生 PNG / JSON 随卡播放器验收

当前机器结果与构建 SHA-256 见 [native-validation.json](native-validation.json)，字体专项结果见 [font-validation.json](font-validation.json)。1.12.2 的大字体结果已经单独[归档](native-validation-v1.12.2.md)，不作为当前字库的测试证据。

## 本次验证范围

- 单元测试 87 项，包含所有内置字库的文件清单、5 MiB 上限、来源哈希，以及五种旧字体选择回退后保留歌曲、歌单、角色绑定和主题。
- 完整插件字体浏览器回归 6 项：旧选择重载与本地音乐保留、离线字库、真实字样预览与键盘选择、批量字体导入/去重/独立删除、旧单字体存储兼容、手机宽度下的失败回退与重试。
- 制作页额外桌面回归 1 项通过：现有歌单、字体和封面配置可导出 JSON 并独立播放。首次测试因滚动事件收起菜单超时，测试辅助操作调整为先滚动到控件、等待事件处理再点击；产品菜单逻辑未修改，未将这 1 项称为整个旧制作页套件。
- 原生随卡浏览器验收 4 项：所选小字体的实际绑定和两种原生格式导出、换字体后重新导出；桌面及手机尺寸的完整播放生命周期；缺失资源和保存失败保护。
- 环境为真实 SillyTavern 1.19.0、官方酒馆助手 4.11.3 和系统 Chromium。移动端为触屏/视口模拟，没有宣称实体手机通过。

## 实际流程

作者端在完整版插件中选择游趣体，导入原创合成 MP3，创建并绑定歌单，从酒馆原生控件实际下载 PNG 和 JSON。检查字体为原始的 1,531,668 字节、SHA-256 与来源记录一致；绑定和两次导出只读取一次打包用字库。核对服务器原始 PNG 和下载文件大小，确认重复角色数据已经精简。

随后作者在原字体选择器改为破晓像素，重新导出 JSON。接收端使用新的浏览器上下文，禁用音乐插件并阻断其资源请求（只允许用于扩展发现的 manifest），确认没有作者的音乐数据库。通过原生文件选择控件导入游趣体 PNG、启用助手脚本、实际加载字体并解码播放；离开角色后检查 DOM、音频、字体、对象 URL、监听与定时器清理。再导入切换后的 JSON，确认只加载破晓像素、没有字体切换或导入控件，并能播放。

普通桌面及手机流程另验证两格式的三首歌播放、音量和进度、歌词、封面和背景、窗口缩放、最近播放；同角色内切换开场白、AI 回复、编辑、重新生成和聊天文件保持同一音频实例。离开角色停止并释放资源，返回重新出现。修改歌名后重新导出包含最新信息；保留角色设定、其他扩展和作者脚本，尊重助手私有数据导出选项。

失败流程实际覆盖本地音频丢失、模拟服务器保存 500、旧式绑定补充脚本、准备资源期间切换角色，以及取消绑定时仅移除本工具的脚本。

完整插件的旧字体回退测试在保存旧设置并重载后，确认界面回退为“跟随酒馆”，不请求已移除的五个文件，本地音乐的 IndexedDB 字节仍然存在。新字体截图见 [fonts.png](../fonts.png)。

## 实测大小

数据记录在机器结果的 `exportMetrics` 中。测试卡包含游趣体完整字库和一首合成 MP3，不是用户实际角色卡的测量。当前字库为两款小字体，总计 2,798,640 字节；已移除的五款字库共 75,924,824 字节。

| 本次测试卡输出 | 字节 | 约 MB（十进制） |
| --- | ---: | ---: |
| 酒馆原始重复 PNG | 8,258,757 | 8.26 |
| 实际下载的精简 PNG | 4,167,688 | 4.17 |
| 实际下载的 JSON | 3,069,405 | 3.07 |

这些数字对应当前游趣体与合成测试音，不等于任意用户歌单的大小。原始大字体的历史测量保留在 1.12.2 报告中。

PNG 只有在核对两份角色数据除格式标识外完全相同时才精简为标准 V2；保留头像与其他字段，并按需重新计算文本块 CRC。不同数据不删除。JSON 原本没有这层重复，不承诺相同比例的减小。

导出耗时包含 Playwright 跟踪、酒馆保存和测试环境开销，没有无跟踪的速度对照，因此不宣传固定倍数提速。每次仍验证用户音频、图片及直链；字体缓存只复用未变的内置文件。

## 验证边界

- 音频实际由 Chromium 解码播放，素材为本项目生成的合成 MP3。
- HTTPS 直链使用浏览器网络路由提供同一音频，验证地址保留及播放通路，不代表外部商业音乐平台可播放。
- 重新生成走酒馆真实流程，LLM/分词回包为固定测试响应。
- 1.12.0 的额外 24 项回归属于历史结果，本次没有全部重跑；本次额外运行的字体回归为上述 6 项。
- 旧版已经分发的卡片自带原脚本和资源，不会被本次更新远程清空或改写；要减小旧文件，需使用新版本重新导出。

## 重现

在隔离的酒馆测试资料目录安装官方酒馆助手和本扩展，启动酒馆，再执行：

```sh
npm ci
npm run build:card-native
npm test
npm run check
CHROMIUM_PATH=/usr/bin/chromium npm run test:card-native
```

完整插件字体测试命令：

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e -- tests/player.e2e.js --grep 'retired font|bundled Poxiao|both compact|batch font imports|a legacy single custom font|font previews fit mobile'
```

字体测试在隔离资料目录临时禁用酒馆助手，完成后恢复原设置；原生随卡测试必须启用官方助手。两个浏览器套件按顺序执行，避免共用资料目录互相干扰。云环境缓存目录不可写时设置 `npm_config_cache=/tmp/stm-ui-build-cache`。本次构建哈希需与机器报告一致。

使用及容量限制见[中文说明](export-guide.md)。
