# v1.13.2 原生 PNG / JSON 随卡播放器验收

最终构建共 **5 / 5** 项用例通过，完整结果见 [native-validation.json](native-validation.json)，权威全局执行记录见 [native-playwright.json](native-playwright.json)。当前构建哈希和范围与 [中文审计](../quality-audit-v1.13.2.md)、[汇总](audit-validation-v1.13.2.json) 对照。

真实 SillyTavern 1.19.0、官方 Helper 4.11.3、Chromium 154；执行原生导出控件、实际保存/下载、全新接收端 PNG/JSON 导入、脚本启用及原创合成音频播放。接收端禁用完整版并阻断其资源，没有作者端音乐数据库。

五项用例分别覆盖：

1. 仅携带选中字体，按字节哈希核对，接收端固定字体；未修改的绑定及两次导出仅一次目标角色写入，换字体后重新导出。
2. 桌面接收端：曲库、歌词、外观、播放控制及同角色聊天/开场白/回复/编辑/重新生成/多聊天连续播放；离开、停用、重启、反复切换及清理。
3. Chromium 手机视口/触摸下的对应流程，**不是实体手机**。
4. 缺失资源、读取期间更改内容、服务器写入失败阻止旧/部分导出；明确解绑只移除本机播放器，保留其他脚本及数据。
5. 保存本机绑定及原生转发外来卡不再移除其自带播放器；明确解绑本机卡仍完成清理，核对服务器真实卡片内容。

HTTPS 直链使用受控网络音频，LLM/分词使用固定响应；这些不证明真实音乐站或模型服务可用。额外接近 30 MiB 文件与官方 Helper 4.9.5 是独立筛选执行，分别保留 runner，不能冒充各自完成整套 5 项。真实外网、Safari/Firefox 与实体设备边界见审计报告。
