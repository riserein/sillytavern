# 把自己的歌单装进角色卡（1.11.0）

> 这是 1.11 单独制作页的历史说明。1.12 已支持绑定歌单后直接使用酒馆原生 PNG / JSON 导出，日常分享请按[当前使用说明](export-guide.md)操作。下文关于“普通绑定不会携带音乐”的描述仅对应旧版本。

现在可以在完整版插件里制作，导出**含独立播放器的角色卡 JSON**。朋友只需要 SillyTavern 和酒馆助手，不需要安装完整版音乐插件，也不需要重新导入 MP3。

## 制作与发送

1. 更新本插件到 **1.11.0**，刷新酒馆。
2. 在“导入”中添加音乐，整理成要发送的歌单。也可以直接使用总曲库。
3. 打开 **曲库 → 角色卡播放器制作**，选择要携带的歌单。
4. 修改导出副本的歌名、歌手、歌词、封面和顺序。需要补歌时可以直接批量添加音频。这些操作不改原曲库。
5. 选择当前配色，或英伦复古、港式黑金、冷灰艺术、现代极简；可以自己改颜色。勾选需要携带的背景、字体，选择雾面/毛玻璃/清透及遮罩。背景使用完整版外观页中已经裁剪好的区域。
6. 点击 **检查资源并生成预览**，在下方播放器点播放试听。配色修改可实时预览；改歌曲、背景、字体等资源后，需要重新检查。
7. 导出角色卡：
   - 正在对应角色聊天中：点 **导出当前角色卡 JSON（含播放器）**。
   - 已有角色卡 JSON 文件：点 **选择角色卡 JSON 并装入播放器**，选你的文件。
8. 将下载的 **`角色名.含音乐.json`** 发给朋友。

**请使用制作页导出的“含音乐.json”。** 普通“绑定角色”仍然只是你自己完整版插件里的歌单切换设置，不会自动装入歌曲。制作页生成新文件，不修改原角色卡；你也可以重新导入“含音乐.json”在自己的酒馆里使用。

JSON 角色卡不包含 PNG 头像图片；这里导出保留的是角色设定、世界书、其他扩展和原有脚本等 JSON 数据。再次制作时，会替换本工具标记的旧播放器，不删除其他作者的脚本。

## 朋友如何使用

1. 安装[官方酒馆助手](https://github.com/N0VI028/JS-Slash-Runner)。本轮验收版本：SillyTavern **1.19.0**、酒馆助手 **4.11.3**。
2. 按平常导入角色卡的方法，导入收到的 `角色名.含音乐.json`。
3. 进入角色，允许该卡运行角色脚本；确认酒馆助手的“角色脚本库”和“角色音乐 · 歌单名”脚本都已启用。
4. 播放器会自动显示，点击播放开始。点击封面看歌词；可切歌、调进度/音量、切换四种播放模式。× 收起成黑胶悬浮球，唱片与窗口都可拖动。
5. 同角色内切开场白、切回复、编辑、重新生成和换聊天时音乐保持。换角色或回主页时停止并清理。

浏览器可能要求亲自点击播放，所以“自动显示”不等于自动发声。返回角色会创建新实例并等待点击播放。

## 音乐到底存在哪里

- **本地音频**：导出时读取音频字节，装入脚本本身。正式输出不包含你当前浏览器的 blob 地址、IndexedDB 引用或电脑路径。发送成功后，即使制作人删除自己的原音频或浏览器曲库，收到的文件仍带着音频。
- **公开直链**：保留稳定公开的 HTTPS 域名地址，不内嵌音频。音源服务器必须继续提供文件；删除远端文件、变成登录可见或链接到期，朋友就不能播放。
- **在线平台来源**：网易云、QQ、Spotify 等受限来源或需要动态解析的来源不能自动打包。制作页会明确拦住；可以换成有权分发的本地文件，或手动提供稳定公开直链。本功能不绕过会员和平台限制。

单首内嵌音频最多 **20 MB**，所有内嵌音频、封面、背景和字体合计最多 **30 MB**；脚本文件最多 45 MB，含原有内容的角色卡 JSON 最多 60 MB。超过时明确报错，不静默丢歌，也不下载半成品。推荐使用压缩后的 MP3，并把大歌单拆开。

资源检查会确认当前浏览器可以读取和解码音频；生成后请实际点播放试听。它不能保证某个外链永远在线，也不保证所有接收设备支持同一种格式。跨设备优先使用 MP3。

## 封面、歌词、背景与字体

- 封面、裁剪后的背景转换为随脚本携带的图片；缺失或无法读取时会提示处理。
- 没有封面的歌曲使用本插件内置插画，导出时也内嵌，朋友不需要访问插件图片目录。
- LRC 和纯文本歌词随歌曲保存，LRC 可跟随进度高亮。
- 内置字体可携带字体文件和对应许可原文，独立播放器内可展开“字体许可”查看。
- 自定义字体需要填写授权/署名说明，或取消携带字体。请只分发你有权传播的歌曲、图片与字体。
- 导出使用选定外观的快照，不依赖制作人电脑上的原插件样式、字体缓存或背景文件。

## 其他输出

制作页还提供独立 JavaScript、酒馆助手脚本 JSON、可独立打开试听的 HTML 和歌曲清单。脚本 JSON 导入酒馆助手时，选择“角色脚本库”，并手动打开库开关与该脚本开关；助手文件导入会将脚本自动设为停用。

这些文件是同一个配置的不同输出。JSON 角色卡已经包含脚本，发送角色卡时不要求朋友再另外导入脚本文件。

## 常见情况

- 导入后没有播放器：先确认发送的是“含音乐.json”，再检查酒馆助手的角色脚本库和对应脚本是否启用。
- 出现两个播放器：制作人原本还安装着完整版插件，或角色里保留了旧三曲测试脚本。本工具保留其他脚本；验收独立版时，可以暂时停用完整版及旧测试脚本。
- 做完后普通导出原卡仍没有音乐：制作工具生成的是新文件，不改原卡。先导入“含音乐.json”，这张新卡之后用酒馆正常导出仍可携带脚本。

## 当前边界

本轮完成“已有歌单/批量音频 → 编辑副本与外观 → 资源检查/试听 → 独立脚本及角色卡 JSON → 另一浏览器导入播放”的流程。制作页关闭后不保留未导出的编辑草稿；尚未提供多项目草稿库和项目同步。JSON 输出没有头像打包功能，制作页使用已裁剪背景，尚未加入独立的背景裁剪器。

真实测试结果与手机模拟的范围见[导出验收报告](export-validation.md)。实体 iOS/Android、其他助手版本以及商业平台完整播放尚未验收，不用普通预览成功替代角色卡环境成功。
