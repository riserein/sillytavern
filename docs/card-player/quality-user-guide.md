# 制作、检查与更新角色音乐播放器

## 给角色卡携带当前播放器

1. 在完整版“导入”页加入音乐，在“曲库”建立歌单并放入歌曲。
2. 打开歌单管理，绑定要分发的角色。确认“音乐已随卡保存”。
3. 日后更新歌曲、歌词、配色或字体后，打开该角色，在“曲库”点“检查 / 重建当前角色的随卡播放器”。当前选择的一款内置字体会被携带，接收端不能切换字体。
4. 从酒馆自身的角色导出菜单导出 PNG 或 JSON。插件会重新检查并读取生成文件，异常会阻止此次导出；请保留原始角色卡备份。
5. 接收端不用装完整版音乐插件，需要安装官方酒馆助手并允许/启用该角色脚本。首次必须手动点播放。离开角色即停止，同角色内聊天、切开场白和 AI 回复应继续播放。

完整版插件已运行时，使用完整版控制音乐，不再额外显示第二个随卡播放器。更新插件不会远程更改已经分发的旧卡，必须重新导出文件。

## 接收端看不到播放器时

制作端能播放不等于发送的文件已经带上播放器。请在曲库展开“随卡分发：接收端没有播放器？”，选择**实际发出的 PNG / JSON**检查。没有播放器记录、脚本缺失/重复或停用会显示原因；不要发送以前下载的原文件。

确认文件通过后，接收端需在酒馆助手允许此角色脚本运行。若首次弹窗选择了取消，请在“酒馆助手 → 脚本库 → 角色脚本”启用。该授权是接收端自己的设置，不随卡替它启用；播放器不会绕过这个开关。没有酒馆助手的原生酒馆不能执行卡内脚本。

已启用仍不显示时，记录酒馆、酒馆助手版本和启动错误提示，提供实际导出的文件检查。v1.13.1 起，新生成脚本的同步/异步启动错误会显示可关闭的提示。旧卡不会自动更新，要在制作端重建并重新导出。文件静态检查通过不等于此设备已运行或已试听。

## 独立制作项目与草稿

“曲库 → 角色卡播放器制作”保留原有的独立制作/预览流程。这里编辑导出副本，不改曲库与角色绑定。

- 每次编辑约 0.4 秒后自动保存，看到“草稿已保存”再关闭浏览器。
- 重新打开会恢复最后的项目；上方项目列表切换项目；“复制项目”保留当前可见编辑并产生新副本，项目名称可直接修改。
- 选择另一个源歌单会创建新制作项目，原项目保留。删除项目只删该制作草稿，不删曲库、歌单和已导出的角色卡。
- 草稿保存在当前浏览器和当前酒馆网址中；换设备、清除站点数据不会自动带走。音频/图片副本会占用浏览器空间。
- 出现“未保存”时请保持页面开启，处理空间或多页面冲突，再复制/导出备份。系统强制关闭无法保证保存最后几笔输入。

## 大小怎么看

点击“分析资源容量（不试听）”，展开“资源大小与验证状态”可看到逐首音频、封面、歌词、背景和字体大小；外链显示为不内嵌。

本地单曲最多 20 MiB，所有内嵌资源最多 30 MiB，脚本最多 45 MiB。图片建议缩小/裁剪，音频可降低码率或改用长期公开 HTTPS 直链，字体选小款。超限不会偷偷删歌。

脚本大小可以精确计算；PNG/JSON 显示的是播放器部分估算，完整文件还要加角色设定、其他脚本和头像。导出完成的实际文件大小才是最终数值。PNG 在两份元数据相同时会删除重复副本，不删除头像或歌曲。

## 歌词为什么可能没有

歌曲能播放不代表音频文件里有歌词。普通 MP3/直链可能只有声音；Oswin 的参考脚本还会联网找词，所以体验不同。

完整版播放页点击封面进入歌词页；无歌词时可点“查找这首歌的歌词”，也可以在“曲库 → 歌曲右侧 ⋯ → 查找歌词”搜索。填正确歌名和歌手，选择一份结果预览，点“确认使用这份歌词”。联网依赖 LRCLIB 的可访问性；搜不到、断网或纯音乐时可导入本地 LRC/TXT。请核对同名歌曲、翻唱、现场版，避免选错。

制作页直接添加 MP3 会读取内嵌 USLT 歌词；展开每首歌曲的“歌词、封面与歌曲顺序”也可导入 LRC/TXT、编辑或查找歌词。已有旧曲库歌曲若导入时没有歌词，需要补词后重新生成。

完整版曲库的歌词沿用酒馆的延迟保存；确认后请等待酒馆完成保存再刷新，制作项目另有草稿保存提示。

歌词保存后会随脚本和 PNG/JSON 一起携带，接收端不依赖联网查词。之前已经导出的文件不会自动长出歌词，请在制作端重建并重新分发。同步 LRC 会跟随进度；TXT 仅显示整篇文字。

## 三种检查不要混淆

- **静态检查**：文件结构、字节、歌曲数量、资源及角色字段核对通过；不代表听过。
- **浏览器解码**：当前浏览器能读取音频数据；不代表其他设备或外网一直可用。生成预览后请实际点播放试听。
- **真实酒馆验收**：把导出的文件在没有完整版插件的接收端重新导入，检查声音、字体、歌词、聊天期间的连续播放和退出停止。

制作页的“核对已导出的 PNG / JSON”能重新检查文件；旧版文件缺少新核对记录时会提示由制作端重建，不会执行不认识的脚本。独立制作页还可导出预览、JS、酒馆助手脚本 JSON 和歌曲清单；不用下载整个插件压缩包。
