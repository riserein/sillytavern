# 2.0.0-alpha.7 歌词模式与接收端显示控制

本轮基于 main `b51ce36`（alpha.6）。保留播放器结构、五种布局、音乐库、歌单、角色绑定、字体、背景、原生 PNG/JSON、酒馆助手脚本及既有生命周期；不改变 IndexedDB 数据格式。

## 使用方法

**外观 → 文字与阅读 → 歌词显示模式**：

- **连续滚动**（默认）：根据当前音频时间在两句之间连续移动；间隔超过 8 秒时先停留，到下一句前 2.5 秒才移动，避免长间奏持续爬行。
- **居中阅读**：换句时用约 450 ms 过渡到新位置；跳播会取消旧动画并立即重新定位。
- **单句沉浸**：显示当前一句，可关闭下一句预览。长句换行并可滚动；没有有效时间戳则显示原文和“无时间轴”提示，不伪造同步。

三种模式复用原歌词解析结果及同一个 Audio。高亮直接按 `audio.currentTime` 判定，视觉移动不延迟高亮。字号、行距、阅读背景继续有效；滚动模式主动浏览后不再自动拉回，点 **回到当前歌词** 恢复。系统“减少动态效果”启用时减少动画。自动跟随偏好控制两种滚动模式；单句模式仍按时间同步。

每句歌词没有独立背景框。保护文字的是整个阅读区的一层主题色遮罩：自动约 95%、透明约 90%、柔和遮罩为实色。透明选项仍保留保护，不能理解成完全取消文字保护。算法将遮罩下的未知图片按黑、白两端保守检查；局部中灰必要时调整阅读区明度，不改写作者锁定的原色，也不持续采样图片。

歌词工具栏的 **歌词时间校准** 提供提前 / 延后 0.1 秒和重置。正值使歌词延后，范围为 ±60 秒；不修改音频或原 LRC。完整版按歌曲保存，导出时携带有效校准；接收者可以覆盖为自己的个人校准，不能回写作者卡片。

## 隐藏、贴边与恢复

打开播放器顶部 **⋯ → 贴边收起 / 隐藏角色音乐**，或到外观中的同名控制。

| 状态 | 界面 | 音乐 | 找回方式 |
| --- | --- | --- | --- |
| 正常 | 普通悬浮入口 / 播放窗口 | 原播放规则 | 点击入口 |
| 贴边 | 左 / 右侧 44×52 像素边缘标签 | 可以继续播放 | 点击标签 |
| 完全隐藏 | 窗口、悬浮入口、标签均隐藏 | 立即暂停，取消睡眠定时，保留选曲和进度 | 魔棒菜单或 Helper 脚本按钮 |

随卡接收端魔棒中显示 **角色音乐播放器 · 已隐藏 / 已贴边 / 显示中**；点击切换隐藏与恢复。导出的 Helper 记录还包含独立的 **显示/隐藏角色音乐** 脚本按钮。这两个入口是不同系统，不把其中一个的测试称为另一个通过。

**恢复只显示入口，保持暂停；点击播放才继续。** 同账号、角色、脚本及项目命名空间保存个人状态；作者默认入口不能覆盖已保存的隐藏偏好。存储不可用时提示偏好仅在当前会话有效。离开角色和停用脚本才完整销毁，HIDDEN 本身不是 dispose。

若魔棒和可见的 Helper 按钮都不可用，拒绝完全隐藏并降级为贴边入口。如果已有隐藏状态在初始化时找不到可靠恢复入口，也降级为贴边。不会更改整个魔棒菜单的显示策略，不删除其他扩展的菜单项。完整版使用原有扩展设置中的“打开音乐播放器”作为恢复入口；HTML 预览使用明确标注的模拟恢复按钮，不能作为魔棒兼容验证。

唯一恢复栏运行中被隐藏或移除时，也会回到贴边状态；控制器对该栏仅观察最多六级祖先的可见性属性与直接子节点；同时观察宿主菜单、魔棒按钮与 body 直接子节点的替换，不观察聊天文本。完整版接管后使用完整版自己的隐藏与恢复入口；Helper 备用按钮服务于实际运行中的随卡实例。

在 **拖动后贴边** 中选择不吸附、保留完整悬浮入口或半隐藏标签。靠近左右边缘时吸附；拖离边缘退出。复用原拖动器，并结合原输入区避让、visualViewport、窗口变化与安全区 CSS 变量限制位置。

## 作者端与更新

设计器及角色卡制作页都有 **接收者默认显示方式**：普通悬浮入口、贴边入口、收起窗口但显示入口。作者不能默认完全隐藏，也不能禁止接收者隐藏、恢复或停止。

制作项目保存该字段、歌词模式与校准。ZIP 备份包含新偏好与草稿；独立副本恢复会重映射校准与播放位置中的歌曲 ID。保留旧库和旧项目，缺少模式字段默认连续滚动。

共享运行时、原生 PNG、原生 JSON、独立 JS、Helper JSON、HTML 预览和保留的经典独立运行时均已接入。**旧分发卡不会自动更新**：更新制作端，重建随卡播放器后重新导出。接收端仍需已启用的酒馆助手角色脚本，不需要完整版音乐插件。

| 源码确认的新增备份缺口 | `data/backup.js` / `card-maker.js`，带 ID 的制作页选择框保存键与备份白名单别名不一致 | 同时保留真实表单键与旧别名，真实 IDB / ZIP 复验确认贴边默认值保留 |
| 新字段兼容处理 | `data/restore.js` 的独立副本使用新歌曲 ID | 映射校准、恢复位置及草稿引用；不当作旧版已确认的数据丢失问题 |

开发中的失败与修复没有从记录中抹掉：[拖动截走菜单](diagnostics/native-menu-pointer-capture.txt)、[隐藏偏好被初始化覆盖](diagnostics/native-hidden-reset.txt)、[遮罩覆盖检查失败](diagnostics/reading-before-mask-specificity.json)、[迟到事件与恢复栏失活修复前](diagnostics/hidden-ended-and-lost-recovery-before.json)、[经典按钮名称回归](diagnostics/maker-before-label.json)。早期测试还修正了隐藏原生 select 的操作方式、非法 / 歧义选择器与拒绝 loopback 音源的预览夹具，没有为通过测试关闭真实校验。灰底问题由最终截图复核发现，保留[修改前截图](diagnostics/menu-style-before/mobile.png)。

真实外网音源、实体设备的软键盘 / 刘海安全区 / 后台锁屏、Firefox/WebKit 及其他酒馆/Helper 版本未由本轮模拟结果替代。代码处理 visualViewport 与安全区，不等于真机验证已通过。

受控迟到事件测试不等于已复现一次自然发生的浏览器竞态；恢复栏失活测试使用真实 DOM 和受控可用性回调，不冒充 Helper API 验收。Helper 按钮的真正点击、事件订阅及角色退出则由单独的实际酒馆用例验证。对比度验收检查稳定渲染与遮罩两端，不认证入场动画的每一帧或每个抗锯齿像素。帧队列和资源计数归零也不等于浏览器进程内存全部归还。

本轮实测的 Helper 为 4.11.3；4.9.5 未重新执行这一整套新功能测试。已知输入区采用原避让机制，其他扩展任意改变 DOM、浮窗或隐藏整个宿主界面的组合未穷举。

共享随卡运行时从 334,018 字节增至 353,180 字节，增加 **19,162 字节（18.71 KiB，5.74%）**。经典独立运行时从 55,127 增至 71,639 字节，增加 16.13 KiB。没有增加第三方运行依赖，没有改动原始音频、打包字体或资源上限；本轮没有新增近 30 MiB 大卡的堆峰值 / RSS 压力验收。[构建大小与哈希](results/runtime-sizes.json)

新增的是一个必要的恢复控制器观察器和歌词几何观察器；切换模式不新建这些对象。单个歌词 rAF 循环只在显示、同步、跟随 / 单句播放或居中过渡期间运行，隐藏和销毁时取消；不采样背景像素。
