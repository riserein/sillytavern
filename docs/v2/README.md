# 音乐播放器2.0使用入口

这是基于原插件续开发的预发布版本。原曲库、IndexedDB、角色绑定、草稿与备份机制保留，旧用户默认夜航。没有离线安装包，也不要求接收者安装完整音乐插件。

1. 导入音乐并建歌单，沿用原有「导入」「曲库」。歌曲爱心可收藏，曲库进入「我喜欢的音乐」；播放页时钟设置睡眠定时，外观调整柔和过渡。
2. 外观 → 播放器形态：选择玻璃卡、黑胶唱片机、磁带或极简；悬浮入口可选黑胶、CD、磁带、胶囊或静态自定义图标。
3. 打开「播放器设计器 · 我的设计」。左侧选形态/主题，中央实际试听，右侧调属性。取消「试听操作」可点击组件选属性；手机用顶部三步切换。撤销/重做、保存模板及应用设计不会重建音频。
4. 我的设计支持重命名、复制、删除、安全JSON分享。错误文件先拒绝，不覆盖旧模板。完整ZIP包括设计及图标；JSON设计文件继承原背景/字体等设置，不等同于整个音乐库备份。
5. 为角色分发：设计器右栏选角色和歌单，保存绑定成功后，用酒馆自己的PNG/JSON按钮导出。接收端启用官方酒馆助手并允许可信角色脚本，即可使用作者布局，音乐插件无需安装。
6. 制作项目需要独立JS/Helper脚本JSON/HTML试听时：进入原「角色卡播放器制作」，点「读取当前设计器配置」，勾选共享界面，再检查资源、试听并导出。原项目默认保留原制作流程。

接收者只有个人音量、动画、收藏及必要无障碍偏好；作者允许后才可改布局，字体保持作者选中款。始终可以停止播放或禁用脚本。更新/回退已经分发的播放器都需制作端重新生成和重新导出，不会暗中改旧卡。
