# 2.0 阶段一：收藏、睡眠定时与柔和过渡

起点是 main `b69ee8d`，实际版本 v1.13.3。先核对播放、存储、备份和原生导出链路，再追加共用功能；未复制音频核心或迁移 IndexedDB。

## 使用

歌曲右侧、详情页及播放页均有爱心，点击即可收藏或取消。进入「曲库 → 我喜欢的音乐」，按收藏时间查看、搜索、播放或勾选多首加入已有歌单。收藏不占自建歌单配额；从总曲库删除歌曲会同时清理其收藏。原曲和文件不因取消收藏改变。

播放页时钟可设 15/30/45/60/90 分钟，也可输入 1 至 1440 分钟；可以暂停/继续、取消，或选本曲结束后停止。关闭播放器面板仍计时；刷新网页、销毁随卡实例后取消。以截止时间而非累计 interval 次数计时；浏览器/操作系统完全挂起期间无法执行 JavaScript，只能在恢复执行时检查，不承诺后台锁屏绝对准点。

「外观 → 柔和播放过渡」可关闭或选 150/300/500/800 ms。默认 300 ms。音量条始终显示保存的基础音量；暂停/恢复及切歌只修改临时音量。静音或音量为零不会被过渡解除。部分移动浏览器不允许程序调整 audio.volume，可能只能正常播放/暂停而无渐变；实体设备尚未验证。

完整插件收藏与过渡时长随已有账号设置保存，并纳入 ZIP 完整备份。恢复时无论音频去重或创建独立副本，收藏均按最终歌曲 ID 重映射。定时任务不会随备份或角色卡恢复为一个过期定时任务。

随卡接收者不需音乐插件，仍需酒馆助手授权角色脚本。个人收藏不会改作者配置或 PNG/JSON，按现有账号/角色/脚本命名空间保存。缺少持久存储或写入失败时提示会话内有效。制作器旧独立运行时也复用 listening.js，不引入完整版依赖。已分发旧卡不会自行升级，制作端需重建并重新导出。

## 改动位置与数据兼容

- `listening.js`：收藏规范化、截止时间状态机、唯一音频上的可取消渐变。
- `listening-panel.js`、`index.js`：共用入口和交互；只使用原 audio。
- `core.js`：追加 `favorites` 与 `transitionDuration`，旧配置默认空收藏/300 ms。
- `data/backup.js`、`data/restore.js`：完整备份收藏及默认来源元数据、恢复 ID 重映射，不更改原二进制 ZIP 格式。
- `card-player/native-entry.js`、`preferences.js`：个人偏好白名单和会话降级提示；`native-export.js` 只携带作者过渡偏好，不携带作者收藏。
- `card-player/runtime.js`：旧制作器脚本追加功能，保留原生命周期和 UI。
- `select-menu.js`：已有菜单实例可增强后追加的选择框，保持磨砂菜单和键盘操作。

新增数据只在原设置对象中追加字段，音乐、封面、字体、原始音频和 IndexedDB v1 不变。回滚时先导出完整备份，再回到前一提交；旧版本会忽略新增偏好字段，因此应保留包含收藏的新备份。随卡脚本已经嵌入导出文件，需主动重建重新导出才能跟随代码回滚。
