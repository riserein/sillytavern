# 阶段五：可视化设计器与我的设计（2.0.0-alpha.4）

从「外观 → 播放器形态 → 打开播放器设计器 · 我的设计」进入。桌面三栏分别是模板与配色、实际播放器、组件属性；窄屏用顶部三步切换。试听操作开启时，中央可以正常播放、切歌、滚动、看歌词；关闭试听操作后，点击组件选择其属性。桌面/手机预览按钮限制中央宽度，预览区域可调整大小。

中央是原来的同一播放器，不创建副本、不移动 audio、不改 src。关闭设计器会撤销尚未应用的预览；已保存的模板仍在。撤销/重做保留最多50份安全配置，重置只修改预览。编辑不会改原歌曲或原窗口位置。离开当前角色或销毁完整版播放器时关闭设计器、取消异步图标处理、清理监听与观察器。

## 可调属性

布局、主题、悬浮入口彼此独立。提供尺寸、材质、圆角、背景透明度、模糊、唱片外圈、胶囊按钮、动画、极简方向/专注、控制显示等受限选项。封面、标题、歌手、进度、按钮、音量、歌词入口、模式、队列、装饰和背景可在模板区域内改显示、尺寸、边距、颜色、透明度、圆角和预设对齐；背景无意义的尺寸/位置控件禁用。播放按钮不会缩到40像素以下。没有任意坐标/HTML/CSS编辑器。

字体可以沿用原外观中的当前字体，或为设计明确选择设备/现有内置字体。原字体选择器仍有效，主动选择后当前设计回到「沿用当前字体」。原生随卡按设计实际字体运输，不增加接收端字体选择。自定义字体随卡授权仍沿用原有限制；设计JSON不搬运未授权字体，也不会重新加入已移除的大字体。

配色可独立锁定后本地随机。文字与背景不协调时调整未锁定的颜色；两者都锁定且对比不足时提示，不擅自解锁。使用现有外观的日夜模式及减少动态效果。

## 模板与分享

填写名称后保存为模板，最多30套，支持选择、重命名、复制、删除。删除模板不删音乐或当前已应用设计。选择模板只预览，点击「应用设计」才修改当前设计。

JSON导出包含安全配置及当前使用的实际静态图标。导入先检查版本、布局、字体ID、组件属性、颜色、数值范围和图片，再预览；错误不覆盖旧设计。1 MiB/2048像素图标限制仍有效，SVG和动画图片不可用。文件最多2 MiB。导入不会执行文件中的脚本；名称以纯文字显示。可以直接导入静态悬浮图标后保存模板。背景及歌曲仍由原外观/曲库管理，模板继承这些现有资源，不宣称JSON分享搬运整个音乐项目。

模板、角色设计、图标纳入现有完整ZIP。恢复沿用资源去重、ID映射、角色映射与失败保护；不升级/清空音乐IndexedDB。

## 角色使用

右栏选择已有角色和歌单，点击「保存设计并绑定歌单」。保存成功后使用酒馆原生PNG/JSON导出；没有购买服务或新增后端。角色设计独立于全局设计；同一歌单可配不同角色UI。更新已分发卡必须制作端重新导出，不会自动改接收者旧文件。完整接收端矩阵继续在阶段六验证。
