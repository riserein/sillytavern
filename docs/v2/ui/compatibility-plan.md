# 跨浏览器与实体设备验收计划

当前已测试 Chromium 154、SillyTavern 1.19、官方酒馆助手4.11.3。手机视口/触摸模拟不代表实体手机。v2尚未重新执行Helper4.9.5矩阵，沿用既有生命周期API不是对该版本新增验收结论。

2026-10-18 补充三种手机尺寸的 Chromium 触摸验证，共 6 项通过，涵盖实际酒馆本地导入/播放、四布局横竖屏切换、歌词/队列/进度与悬浮球拖动，以及受控随卡重复执行/角色退出清理。详见 [虚拟验证记录](mobile-virtual/README.md)。WebKit 下载被云网络策略拒绝，Firefox 尚未安装，本次均未运行；下表中的实体设备和其他浏览器仍保持未验证。

逐项先备份，在独立测试账号/数据目录导入原创或授权测试音乐。创建A、B两张角色卡，各绑定不同设计和歌单，用酒馆原生PNG及JSON导出，在禁用音乐插件的独立接收账号导入，明确同意可信角色脚本。

每种环境记录：具体系统/浏览器/Helper版本、导入/导出时间和实际字节、首次显示及可播时间、能否滚动触及全部控制、音量/进度、收藏、歌词/队列、定时器、开场白/AI回复/聊天切换、A→B→A重复10次、脚本停用、字体/音频读取中退出、原曲及项目是否仍在。失败应保留控制台/服务器错误，不上传私人聊天或凭据。

后台完全挂起时JS无法保证定时回调准点；恢复时核对截止时间。部分iOS版本不允许网页修改audio.volume，渐变可能降级为普通播放/暂停，不能通过额外音轨或自动播放绕过限制。低内存测试要记录系统终止及恢复，不能仅以一张JS堆快照描述内存峰值。
