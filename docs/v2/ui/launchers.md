# 阶段四：五种悬浮入口（2.0.0-alpha.3）

外观 → 播放器形态 → 悬浮组件，可选黑胶、CD、磁带、音乐胶囊、自定义图标。胶囊提供播放/暂停及可选下一首；使用原 audio、队列与过渡。所有入口复用原拖动和位置记忆，切换不选曲、不重置进度。

图标支持静态 PNG/WebP，原图不超过 1 MiB、2048×2048。检查文件头、动画标记与像素尺寸后才解码，保存为最大512像素的独立图片副本。可调整尺寸40–88、形状、边框0–4和透明度。失败时保留旧图标；异步保存中角色或设计改变时不覆盖新角色，只删除刚创建的无主副本。有效模板/草稿引用仍由现有引用图保护。

移动端只读取酒馆输入框位置，不读取聊天内容。窗口/可视视口变化、拖动结束及输入框尺寸变化会重新夹紧位置并避让输入区；视觉动画尊重减少动态效果。实体键盘弹出场景尚需真机验收。

原生 PNG/JSON 以实际静态图标字节运输，不携带本机 IndexedDB ID。接收端使用会话内资源 ID；不提供导入图标功能。图标计入原30 MiB总资源限制并受单图1 MiB限制，缺失资源阻止更新，保留旧随卡数据。相同歌单的UI变体共享已编码音频和字体字符串，图标缓存仅在当次任务内有效。
