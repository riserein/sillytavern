# 数据备份、换设备与存储管理

在播放器打开 **外观 → 数据备份与恢复**。

## 保存完整备份

点击“导出完整备份 ZIP”，等待完成后保存下载文件。备份包含当前账号的本地音频原文件、歌曲资料与歌词、歌单及排序、角色绑定、封面、背景和原图、自定义字体、外观及窗口设置、音量与模式、最近播放/排行，以及全部已保存制作项目。歌曲和草稿中的同内容文件按真实字节去重，恢复时仍保留各自引用。

在线歌曲只备份信息和链接，换设备后仍需网络和有效音源；没有下载远程音乐。插件不会备份聊天、Cookie、密码、平台 Key 或整个酒馆设置。链接中常见认证参数会移除并提示，恢复后可能需要重设该链接。请勿在歌名、歌词、备注或任意链接路径中放密码；自动检查不能识别任意文本中的所有秘密。

ZIP 使用独立二进制文件及 SHA-256 校验，不是 Base64 音乐大 JSON。请保留插件原始 ZIP，不要解压重压、改名内部文件或改内容。单项资源目前上限 128 MiB、目录上限 64 MiB；超限或资源缺失会报错，不下载静默缺歌的备份。没有验证多 GiB 备份的所有设备兼容性。完整备份本身含私人曲库和制作项目，请妥善保管。

## 换设备或恢复

1. 在新设备安装兼容版本插件并登录自己的酒馆账号。选择 ZIP，等待版本、字节数及每个文件 SHA-256/CRC 校验。
2. 选择“合并”“仅恢复缺失”或“独立副本”。合并保留已有歌曲编辑和歌单顺序，补入缺失内容；仅恢复缺失跳过已有项目；独立副本为本地歌曲、歌单、项目创建新 ID。同一平台歌曲仍按平台标识复用。
3. 核对旧角色绑定，重新选择本机角色；未选择的绑定不自动套用到同名角色。需要时勾选同时恢复外观等偏好。
4. 点击“核对恢复计划”，检查新增、重复、冲突、未映射绑定和暂存体积。容量或当前曲库条目上限不足会阻止恢复，不会截掉歌单尾部。
5. 点击“确认恢复”。期间不要切换账号或关闭页面。完成后点“刷新酒馆以应用恢复的数据”；正在生成回复时可稍后刷新。

恢复先暂存新文件和项目，再交给酒馆正常保存设置并回读核对。已有内容不先清空。浏览器数据库与酒馆服务器不是同一个事务；网络断开可能无法立即判断保存结果。此时不要清空浏览器，在“未完成恢复记录”点“核对未完成恢复”：确认已保存则核对引用；确认未保存则只回收本次拥有的新文件；结果仍不明确时保留记录和文件。已经被再次编辑的数据不会作为临时文件自动删除。

备份合并不是撤销既有操作的按钮，恢复前也建议备份当前状态。恢复失败不会覆盖手上旧 ZIP。临时文件可能占用空间，需等恢复记录确认后再处理。

## 升级后旧文件待确认

旧版文件按浏览器地址共享，插件不能猜哪些草稿属于哪个账号。旧文件仍在原数据库。展开“旧设备数据归属确认”，确认归属、显示并选择自己的草稿，再“预览复制到当前账号”及“确认恢复”。当前账号曲库引用的旧音频、图片和字体一起复制。原库不改名、不清空、不删除，其他账号不会被自动认领。

复制需要额外空间。不要为解决配额不足直接清除站点数据；先保存备份、整理不需要的内容或换空间充足的浏览器。若无法确认归属，不要勾选或迁移。

## 安全清理

展开“存储空间”，先扫描。各类占用是逻辑字节；浏览器显示的剩余容量属于整个酒馆地址，不是某账号专用。只有未引用且已确认保存的待回收文件才会列入预览。确认后会再次校验；未知资源、其他账号、旧库和未完成恢复文件不会删除。没有候选时不需要清理。

“申请保留浏览器存储”取决于浏览器授权，即使成功也不能防止主动清除站点数据。请定期把 ZIP 存在浏览器之外。角色卡 PNG/JSON 随卡导出只运输该播放器所需资源，不能替代完整私人曲库备份。
