# 在你自己的酒馆检查真实在线播放

这页给普通使用者操作，不需要申请 Key、部署服务器或下载 MP3。搜索结果存在不等于能播放。当前默认只有 Openverse 搜索入口；它主要是公开许可音频，也包含环境声，不等于网易云或 QQ 的商业曲库。

## 直接在播放器里检查

1. 更新扩展，刷新酒馆，打开 **导入 → 在线搜索**。
2. 输入 `piano` 或 `rain`，点击搜索。若提示无法连接、安全验证或次数限制，请保留提示；这时没有完成搜索和播放验证。限流时稍后再试，不必反复点。
3. 有结果后，可以点 **检查播放**。它会把所选歌曲保存到你的曲库及所选目标歌单，并尝试真实播放，检查期间不要切歌；检查本身不自动停止已开始的音乐。也可以直接点图标试听。
4. 只有浏览器真正加载音频、触发播放并且进度前进至少半秒，才显示“真实播放已通过”。**你还需要确认自己听到声音**，因为系统静音、设备输出和音量不是网页能确认的。
5. 暂停后继续，确认进度接着走；拖动进度、调整音量，再试听另一首。一次通过不能证明所有歌曲、地区、网络或手机都可用。
6. 加入歌单，在 **曲库 → 歌单 → 管理此歌单 → 绑定角色** 中绑定一张卡。切入角色应只切歌单、手动播放；退出聊天应暂停。刷新后曲目、署名和绑定保留，不自动播放。

若加载失败，插件会说明连接、格式、解码或来源限制等可能原因；再点播放会重新获取支持平台的音源。无法从浏览器错误唯一判断的原因不会写成确定结论。网页安全验证不能在后台跳过。

## 分享链接与大歌单

在 **导入 → 分享链接** 粘贴完整地址并读取预览。能读取的公开歌单会完整读取所有可访问页，显示总数、作者、封面和播放能力。曲库上限仍为 200 首：超出后不会自动截断。

你可以取消勾选，或点击 **按剩余容量选择**，核对“已选 / 原歌单总数”后再确认。未选的曲目不会导入，来源总数仍保存。**只选可直接播放** 会排除受限项。两个条件不同：可播放数也可能仍超出剩余容量，需要进一步选歌。已存在的同平台 ID 会复用。

目前默认无法读取商业平台公开歌单，不能执行这个流程；只保存来源的歌曲也不会有必然失败的播放键。当前 Audius 分页功能需维护者完成应用接入和实测，普通用户不填写 Key。

## 给开发者的自动检查入口

这是可选的开发检查，不要求普通安装者运行。使用已安装开发依赖的仓库和正在运行的测试酒馆：

```sh
CHROMIUM_PATH=/usr/bin/chromium ST_BASE_URL=http://127.0.0.1:8000 npm run test:live
```

Windows PowerShell 使用自己的酒馆地址时可运行：

```powershell
$env:ST_BASE_URL = "http://127.0.0.1:8000"
$env:ST_LIVE_REPORT = "$env:TEMP\sillytavern-music-live.json"
npm run test:live
```

先按 README 安装 Playwright 浏览器或设置 `CHROMIUM_PATH`。检测在酒馆页面内使用真实前端服务模块和真实 HTML Audio，**不会替换外部 API 或音频响应**。为保护数据，单独拦截本次诊断页的宿主设置保存，并给本页提供空播放器状态；不修改你的曲库，不创建角色卡。这些宿主设置隔离会记录在测试说明中，与外部 API Mock 区分。

默认结果文件为系统临时目录的 `sillytavern-music-live.json`，可用 `ST_LIVE_REPORT` 改路径。退出码 `0` 仅表示至少一个已启用来源观察到实际播放；退出码 `2` 表示未通过或环境受阻，不能当成功。无声的生成音频测试与此命令是两套检查。

维护者配置好的公开 Audius Key 会从插件配置使用；诊断时也可通过 `AUDIUS_PUBLIC_API_KEY` 临时提供公开应用 Key，报告不输出 Key。**不要使用 Bearer Token 或私人凭据**。`--anonymous-audius` 只诊断公开接口，不能启用正式适配器；`--candidate-embeds` 只探测候选元数据，不代表已获产品使用许可或播放器已发声。

需要使用云环境已配置代理时可设置 `ST_LIVE_USE_PROXY=1`；仅使用环境提供的代理。若 Chromium 报 `ERR_CERT_AUTHORITY_INVALID`，应检查受信任证书配置，不能关闭 TLS 校验。本次云端为此尝试添加环境 CA，被自动审批拒绝，尚未修改信任库。你自己的电脑不需要安装云环境的证书。
