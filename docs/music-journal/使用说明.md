# 角色音乐场景与私人音乐手账

## 制作角色场景

1. 将音频文件或稳定直链加入原有曲库。场景引用已有歌曲，不额外复制原音频。
2. 打开「曲库 → 角色音乐场景」，选择实际角色卡。
3. 新建场景，选择歌曲，用箭头调整歌曲及场景顺序。可填写介绍、歌曲手记，添加封面／背景，选择场景主题。
4. 指定作者默认场景，勾选要随角色卡导出的场景，点击「保存角色场景」。未完成场景可以保存，但不能作为完整场景导出。
5. 返回播放页，通过「场景」切换配乐。暂停时切换仍保持暂停；共用当前歌曲时优先保留播放进度。

每角色最多 12 个场景；介绍最多 300 字、每首歌曲手记最多 500 字。保存按钮将配置交给酒馆保存；请留意酒馆保存错误，并定期做 ZIP 备份。玩家上次选择优先于作者默认；不同角色分别记忆。

## 使用手账

在「外观 → 播放器形态」选择 Music Journal｜私人音乐手账。可选复古羊皮纸、冷灰档案、午夜手账、现代极简杂志，也可沿用原主题。

桌面是双页，左页封面与音乐控制，右页切换歌词、角色手记、目录。窄窗口／手机使用单页，并提供明确栏目按钮；音乐页内容较多时可在书页内滚动。点击目录实际切歌，翻页不会重建音频。原三种歌词模式、校准、手动阅读和回到当前歌词仍可使用。

设计器可调整纸张颜色、纹理、边缘、装订、比例、留白、标题字重、装饰线、翻页和默认栏目；原封面大小与字体设置继续有效。联合预览可选择当前角色场景，关闭预览不覆盖正式配置。预览可能按你选择的场景切歌，不承诺回滚试听进度。

## 分发角色卡

**原生导出：** 在酒馆自己的角色卡导出菜单选择 PNG 或 JSON。插件会检查当前角色的场景／歌单并构建随卡播放器。也可先用曲库的「检查 / 重建当前角色的随卡播放器」，然后重新导出。

**独立制作项目：** 打开「角色卡播放器制作」，点击「管理角色音乐场景」，保存后点击「读取当前角色场景」。读取会合并场景所需歌曲，保留项目已有编辑。源角色后续修改不会自动覆盖项目，需主动重新读取。场景和手账采用共享播放器导出，可生成 JS、酒馆助手脚本 JSON、预览 HTML、歌曲清单及含播放器的角色卡 JSON。

接收者无需安装完整版音乐插件，仍需安装并启用酒馆助手、确认可信角色脚本的运行权限。进入角色显示入口，离开角色清理；同角色聊天切换不应重建播放器。音频必须由接收者点击播放，浏览器可能限制自动播放。接收者的隐藏偏好优先，可从魔棒菜单恢复。

仅勾选的有效场景会随卡携带。默认场景也必须勾选；全部取消会阻止导出，不会擅自换成别的曲库。共用歌曲按 ID 只携带一次；未勾选场景的独有手记／歌曲不会加入。缺资源、不可分发的临时地址或超限时整个导出失败，原角色卡保留。沿用单首 20 MiB、资源总计 30 MiB、脚本 45 MiB 等既有限制。不会压缩或改写原始音频。

本地音频作为内嵌字节分发；网络音源仍需要长期可访问。平台来源书签不是可播放音源，不能靠场景功能变成完整在线播放。

旧版已发出的角色卡不会自动升级，必须由制作端重建并重新导出。

## 备份与恢复

在外观设置的数据工具中导出完整 ZIP。场景、手记、手账配置、角色偏好及制作项目都会保存；图片／音频等二进制为独立文件，按 SHA-256 去重。在线歌曲保存信息和地址，不等于离线备份远程音频。

恢复时先校验备份、选择合并／缺失／独立副本，并核对角色映射，再生成预览并确认。更换酒馆后角色文件 ID 可能变化，不按角色名字自动猜测。缺少映射会阻止场景恢复；超限不静默删歌。恢复失败不会清空原曲库。需要回滚时保留恢复前 ZIP，并使用现有恢复阶段记录核对处理，避免直接删除数据库。

若回退到 2.0 程序，先保留 2.1 ZIP；旧版不认识新场景字段，再次保存可能忽略它们。更安全的做法是恢复升级前的备份，或继续用 2.1 修复版本。原来的音乐库 IndexedDB 结构没有改变。
