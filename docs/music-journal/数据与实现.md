# 2.1 数据与实现

不升级原音乐库 IndexedDB。原音频、歌曲和歌单继续使用既有 ID；新字段由账号设置保存：

```js
roleScenes: [{
  avatar: '实际角色 avatar 引用', version: 1,
  defaultSceneId: 'scene:UUID',
  scenes: [{ id, name, description, trackIds, coverId, backgroundId,
             themeId, included, order }],
  notes: [{ trackId, text }], showNotes: true, keepCurrent: true
}]
scenePreferences: [{ avatar, sceneId }]
```

`avatar` 是酒馆角色文件引用，不是显示名称，也不是权限凭据。原账号存储隔离机制继续负责账号边界；接收端继续使用账号／角色／脚本命名空间。场景引用数组保留曲目顺序，缺失引用保留为草稿。图片仍保存在现有 Blob 库，前缀为 `cover:` / `background:`；背景原图为 `:original` 后缀。原始音频字节不改写。

`sceneSelection` 在导出边界筛选场景、校验默认场景与草稿、计算有序歌曲并集；不按同名歌曲合并录音。共享同一歌曲 ID 的不同场景只生成一条音源。源数据与作者个人选择不修改、不携带。便携配置新增 `sceneSet` 与 `sceneAssets`，仍由既有导出容量与完整性检查器校验。

原生导出为仅配置场景的角色生成稳定的内部集合 ID；该 ID 不替代实际角色作用域。生成代码仍使用同一共享播放器构建，接收端无完整插件数据库、在线搜索或制作入口。图片和音频由既有可取消嵌入存储延迟解码，场景切换的临时 URL 由序号防止异步过期结果重新挂载，并在替换／退出时释放。

制作项目使用 `sourceSettings.sceneSet`，图片副本使用 `assets.sceneBlobs`。完整 ZIP 将它们转为有字节大小和 SHA-256 的独立资源记录，不把项目图片写成超长 Base64 JSON。恢复重映射歌曲、场景、资源和角色引用，场景冲突计入预览；超过上限拒绝写入。图片原图与已选手账配置保留。新增场景数据不包含酒馆聊天内容或平台凭据。

## 主要文件

| 文件 | 职责 |
|---|---|
| `music-scenes.js` | 纯数据规范化、验证、选择、导出筛选和引用映射 |
| `music-scenes-panel.js` | 制作端场景管理与共用场景选择弹层 |
| `ui/journal.js` | 移动原有封面、控制和歌词 DOM 到书页；恢复旧布局 |
| `ui/journal.css`、`ui/scenes.css` | 书页、翻页与场景组件样式；不为普通文字添加背景 |
| `ui/config.js`、`ui/presentation.js`、`ui/editor.js` | 布局注册、四主题、可编辑属性与联合预览 |
| `index.js`、`core.js` | 原队列／Audio 接入、角色事件、状态持久化和兼容回退 |
| `card-maker.js`、`card-player/project-store.js` | 场景项目捕获、草稿资源副本、独立导出 |
| `card-player/native-export.js`、`native-entry.js`、`shared-export.js` | 原生角色卡桥、独立共享运行时与预览 |
| `card-player/config.js`、`export.js`、`quality.js` | 便携数据、资源打包与完整性／容量校验 |
| `data/backup.js`、`restore.js`、`storage.js`、`panel.js` | 二进制 ZIP、引用重映射、存储保护与恢复预览 |
| `asset-retirement.js`、`card-player/resource-references.js` | 场景资源回收保护 |
| `scripts/build-native-player.mjs`、`card-player/dist/*` | 同步完整插件与随卡播放器的实际共享构建 |

没有新增 Audio 引擎、歌词解析器、聊天内容分析、AI 请求或商业音乐接口。阅读衬底保持整页保护，纸张是完整书页组件；普通说明、手记和歌词继续使用透明背景与不透明文字。
