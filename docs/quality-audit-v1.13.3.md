## 实际新增能力

**完整备份恢复。** 外观页增加“数据备份与恢复”。版本化 ZIP STORE，原二进制独立文件，每项字节数与 SHA-256，ZIP 再检查 CRC/头信息/目录/重叠/路径。包含歌曲原文件、元数据、歌词、永久歌单排序、绑定、图片与背景原图（也保留草稿仍可找到的旧背景原图）、自定义字体、外观/窗口/音量/模式/历史、全部已保存制作项目。远程音乐只保留元数据和 URL，不声称离线备份。按白名单排除宿主聊天、Cookie、Key 和整个酒馆设置；常见 URL 认证参数移除并提示。不能识别用户任意文本中自行粘贴的所有秘密。

恢复有版本/完整性校验、预览、容量估算、合并/补缺/副本、音频真实字节去重、项目 ID 冲突及角色重新映射。超限或缺失明确失败，不静默截歌。先记录阶段，再分别事务写入资源和项目，最后由酒馆正常保存完整设置并回读；绝不向宿主直接发送只含插件字段的“完整设置”。未完成记录保留后可核对，回滚只删本次创建、归属/校验仍符合、未再被编辑或引用的新数据。复用文件在执行前重校验。完成记录缩成计数摘要，避免长期重复保存全份歌词/设置。

IDB 与服务器 **不是一个事务**。网络断开或发布响应不明时保留文件；读回等于 after 则确认，等于 before 则安全回滚，否则等待人工核对。恢复期间锁定其他播放器编辑；服务器预检返回后再次比较本地状态，避免覆盖等待期间的新编辑。其他标签/不合作扩展与服务器间仍没有通用 CAS 保证，不能宣称天然跨系统原子性。

**账号与旧数据。** 使用官方 /api/users/me 的内部 handle + created，不用显示名称；身份不明锁定本地读写。曲库、草稿、最后项目键与维护记录按账号隔离，旧 DB 名称/版本/存储结构保留。旧库先仅显示数量，确认归属后才显示项目，选择并预览复制，不删除或改名。新标签验证账号后发同源通知，后台旧播放器停止；旧页面继续保存会被拒绝，直到刷新。无 BroadcastChannel 时退回聚焦/保存前检查，后台通知不承诺即时。

随卡偏好使用官方 accountStorage，并维持角色/脚本/项目区分；旧全局偏好明确确认后复制，等待授权写入完成才重建。缺官方存储的旧宿主只保存会话偏好。字体准备与实际挂载共享账号保护租约，退出释放；制作预览的 opaque origin 禁止 localStorage 时仍可正常播放。完整版接管前先清理随卡保护，防止自身包装链不必要地持有已退出 iframe。

**存储管理。** 按当前账号有效资源、歌单、草稿和未完成恢复构建引用；扫描→预览→确认→服务器核对→重扫→删除→复核。未知格式、未知引用、其他账号、旧库、保存未确认和恢复未完成文件保留。各分类是逻辑字节，浏览器配额是整个 origin 估算。未确认资源回收记录持久化；维护记录配额失败不能把成功的宿主保存伪装为失败，也不能误删文件。没有默认破坏性清理或自动删除未知孤儿。

**大型卡。** 内嵌歌曲按需解码，分段让出主线程，相同未完成读取共享结果，离开角色取消并清空缓存/任务；不改音频字节、不绕过 30 MiB。具体单次前后测量和限制见 [性能记录](v1.13.3/performance.md)，没有把堆快照或最大采样值称作峰值。整体 Helper 链路高内存仍未解决。

## 剩余风险与未验证边界

1. **大型 Helper 内存仍高。** 本轮没有降低整个导出链路的数 GiB RSS 观察值，原生 PNG/JSON 仍需较大字符串、序列化和服务器/Helper 处理。低内存实体手机、系统内存峰值、多 GiB 备份、数万草稿和系统回收未验证。未引入转码或收费服务。
2. **第三方 Helper 的临时导出过滤。** 4.11.3 源码 character.ts:116–150 会临时保存过滤后的脚本字段并异步恢复；实际观察过恢复前的短暂过滤状态，最终服务器状态回归通过。断网/关页导致永久保留过滤状态的后果本轮没有故障注入复现，不将其写成本插件已确认的新永久丢失 Bug。播放器本身只过滤下载文件；不擅改 Helper。涉及其他脚本私人变量时仍需酒馆数据目录的独立备份，音乐 ZIP 不备份其他扩展的私人数据。
3. **权限与隔离边界。** 已获准的角色脚本/恶意同源扩展可访问主页面和数据库；逻辑账号命名空间不是安全沙箱。少见的宿主登录初始化竞争、账号记录重建、代理替换及其他扩展自行保存，不能靠客户端检查宣称绝对原子隔离。收到账号变化提示应刷新旧页面。
4. **网络边界。** 当前环境真实 Openverse 探测返回 403，公开 MDN CC0 音频探测也受阻，见 [本轮探测](v1.13.3/external-network.json)。未通过真实外网浏览器播放验证；不等于平台本身不可用。直链实际播放回归使用明确的受控网络音频响应，本地音频解码则是真实的。Audius 无维护者公开 Key，仍未擅自启用。
5. **存储与兼容性。** 压缩文件字节限额不是图片解码像素上限，浏览器音频流也没有本插件统一的内存硬帽；这是上轮风险的延续，不能说已经解决。 浏览器清站点、隐私模式、OS 回收、未知格式、配额估计不准仍可能造成不可用。未知或未确认文件可能继续占空间，这是防误删的取舍。Firefox/WebKit、Windows/macOS、实体 iPhone/Android、后台锁屏和播放设备切换未实机验证，计划见 [兼容性矩阵](v1.13.3/compatibility.md)。其他扩展保留旧转发 wrapper 可能延长脚本 realm 生命周期，计数归零不证明整个浏览器立即释放所有内存。

## 普通用户操作与回滚

完整步骤见 [中文备份恢复说明](data-maintenance.md)，账号/迁移/清理实现边界及阶段回滚见 [阶段 D](v1.13.3/account-and-storage.md)。升级后先确认旧库归属并复制，再导出完整 ZIP；更换设备后重新映射角色，勿按名称自动认领。旧数据库一直保留，不执行静默破坏性迁移。

既有制作项目和角色脚本配置保持兼容；已经分发的旧卡不会自动改写，需制作端重建、重新导出，接收端重新导入才获得新生命周期/偏好保护。代码回滚前先导出新账号库备份并核对未完成恢复；旧代码无法直接看到新命名空间，不能把降级后看不见的数据误认为已迁回旧库，更不能删除它们。
