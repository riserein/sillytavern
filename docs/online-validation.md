浏览器用例不会用 Mock API 的“可播放”字段当作播放成功。受限/纯来源书签没有站内播放按钮，也不写入播放历史；可播放的测试记录必须实际触发音频 `playing`。

正式默认曲库仍为空。没有将测试音频或随意挑选的歌曲作为用户正式预设。报告中的平台能力与本次实际默认启用范围见 [在线平台报告](online-platforms.md)。

云环境测试域名已经保存配置草稿。需要在环境设置中应用网络变更后，才能继续外部 API、CORS 和真实音源验证；草稿保存本身没有证明当前实例已联网。这一步属于开发验证，不要求插件普通安装者部署服务或填写 API Key。
